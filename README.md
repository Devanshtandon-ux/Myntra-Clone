
# Myntra Clone

A lightweight frontend clone of the Myntra e-commerce layout built with plain HTML and CSS. This project demonstrates responsive layout techniques and a simple product-list UI suitable for learning and small demos.

## Features

- Responsive, mobile-first layout
- Clean product grid with images
- Simple navigation header and footer
- Lightweight: no JavaScript or frameworks required

## Preview

Open `index.html` in your browser (or use a local server) to view the project.

## Installation & Run

Prerequisites: a modern web browser. Optionally, use VS Code Live Server or Python's simple HTTP server for a proper local origin.

1. Clone or download this repository.
2. Open the project folder and open `index.html` in your browser.

To run a local HTTP server with Python 3 (recommended for loading images consistently):

```powershell
cd "c:\Users\lenovo\Desktop\myntra clone\clone"
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

Or, using VS Code Live Server: right-click `index.html` -> "Open with Live Server".
